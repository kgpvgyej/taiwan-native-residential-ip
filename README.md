## 原生 IP 解決「是不是台灣」，住宅 IP 解決「像不像台灣家庭」

這句話值得記住，它是整篇選購邏輯的骨架。兩條線都能讓動畫瘋認出你在台灣，但只有住宅 IP 能讓 TikTok 的風控系統相信你是台北某間公寓裡的普通用戶。

**原生 IP 是什麼。** 由 TWNIC 直接或間接分配、納入台灣本地路由表的 IP，WHOIS 註冊國是 TW，從台灣本地 IX 出去。它比「骨幹繞香港再回台灣」的偽台灣 IP 延遲低、地區解鎖穩定。但注意，麗薩主機這條線的 IP 歸屬是 BGP 機房段，本質上還是 Datacenter，只是註冊地與路由在台灣。

**住宅 IP 是什麼。** 麗薩主機的住宅線用的是中華電信 HiNet 的家用寬頻撥號 IP，ASN AS3462，在主流 IP 庫裡標記為 Residential 而不是 Datacenter。平台看到的是一條家庭寬頻連線，不是託管商機器。

**「雙 ISP」又是什麼。** 這是這條住宅線的加分項：IP 在某一個 ISP 層註冊，上游連線經另一個 ISP 路由，風控更難把它歸類成託管 IP，看起來像「ISP A 提供 IP、ISP B 提供連線」的真實家庭寬頻配置。這也是為什麼它的價格比一般原生 IP 高出一個級別：住宅 IP 的採購成本本身就高。

## 拿到機器後，怎麼確認這是真的原生 IP

這一節不是走流程，而是簽約前就該做的事。第三方技術資料裡列的驗證方法有四條：

1. **查 WHOIS 註冊國**，應該是 TW。
2. **查反解 DNS**，應該指向台灣網域。
3. **跑 traceroute**，看是否經過台灣本地 IX（例如 TWIX），而不是繞香港或新加坡的專線。
4. **簽約前要測試 IP**，用實際 IP 驗證，不要只看宣傳頁。

常見的坑也寫得很直白：號稱台灣機房、實際骨幹繞香港；IP 是原生但 GeoIP 資料庫指向香港或新加坡；大量採購時折扣談不下來導致預算超支。如果是規模化部署，建議先用 5–10 台做 PoC 驗 IP 原生性與路由，再幾十台試跑，最後才上百台自動化。

住宅線的驗法則換一套指標：**看 ASN 是不是 AS3462（中華電信 HiNet），看 IP 在 MaxMind／IP2Location 裡是不是標 Residential**。這兩項對得上，「住宅」兩個字才成立；只看 WHOIS 國別是 TW 是不夠的，機房 IP 的國別也可以是 TW。

## 網路這件事：它不是大陸直連優化線路

麗薩主機所有台灣產品線的頁面都掛著同一句話：非大陸直連優化網路，建議通過香港或日本線路中轉使用。這句話會直接影響你的使用體驗，買之前必須接受。

第三方測試顯示的路由是這樣：中國電信走 163 普通直連，聯通走 AS4837，移動走 CMI 主幹，全程沒有 CN2 GIA 或 9929 這類大陸優化路由。延遲方面，不同測試給出的區間有出入，綜合來看大約落在 **80–190ms**，平均在 100ms 上下，晚高峰會有丟包波動；聯通和部分地區移動的直連表現相對好一些，個別節點能壓到 50ms 以內，電信用戶則普遍需要中轉。

對 TikTok 運營、電商後台這類非即時業務，100ms 出頭完全夠用。但如果你指望它像 CN2 GIA 那樣打遊戲、做即時通訊，會失望，這條線從設計上就不是幹這個的。

官方推薦的做法是：另外準備一台香港 CMI／CU2／CN2 或日本原生 IP 的機器做前端中轉，回程走優化線路，再轉發到台灣這台。終端出口仍然是乾淨的台灣 IP，風控視角不受影響，大陸這邊的訪問體驗會順很多。**電信用戶、尤其是晚高峰時段，中轉基本是剛需。**

另一個官方明確建議是**開啟 BBR**。非優化線路上，擁塞控制演算法對實際吞吐的影響很明顯，中轉場景下差別更大。

硬體方面，全線 KVM 加 NVMe SSD，第三方測試的磁碟 I/O 約 142 MB/s；500Mbps 套餐測得上傳約 420 Mbps、下載約 470 Mbps，頻寬沒有嚴重超售。2GB 記憶體及以上的套餐可以提工單裝 Windows。
